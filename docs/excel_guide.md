# Excel manager pack guide

## Sheets

| Sheet | Use |
|---|---|
| Summary | Executive KPI cards, revenue/target trend, margin/return trend, action queue |
| Monthly KPI | Auditable source inputs and formula-derived economics/rates |
| Exceptions | Root-cause ranking with formula-derived severity and decision cues |
| Action Register | Editable priority, owner, status, and formula-driven progress |
| Forecast | Planning benchmark, 95% interval, risk flag, backtest diagnostics |
| Definitions | KPI formula, grain, owner, direction, threshold |
| Sources | Provenance, real-versus-synthetic classification, disclosure |
| Checks | Data-quality and reconciliation evidence plus formula-based workbook gate |

## Editing rules

- In `Monthly KPI`, blue cells are source inputs; green/white cells are formulas.
- In `Action Register`, use the drop-downs for Priority, Owner, and Status.
- Do not overwrite formula columns such as Net Revenue, Contribution Margin, rates, variances, Progress, Severity, or Workbook Status.
- A red or failed `Workbook Gate` means the manager pack should not be used for a decision until the upstream evidence is corrected.

## Rebuild

The committed workbook is generated by `scripts/build_excel_manager_pack.mjs` using the repository analysis artifacts. The build process inspects key formulas, scans for Excel errors, renders every sheet, and exports one `.xlsx` file.

## Validation result

The current release contains eight sheets, formula-backed KPI cards and helper ranges, three native charts, table filters, controlled inputs, comments, no matched formula errors, and a visible PASS gate over 32 checks.
