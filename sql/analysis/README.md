# SQL analysis portfolio

These 24 PostgreSQL queries answer specific management questions against the dbt marts. They deliberately demonstrate window functions, cohorts, funnels, CTEs, conditional aggregation, percentiles, ranking, contribution bridges, period comparisons, rolling metrics, and operational exception logic. Run `dbt build` first.

The queries are methodology assets; the reader-facing findings live in `artifacts/analysis` and `docs/decision_brief.md`.
